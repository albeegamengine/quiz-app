# プロダクト規約

## アプリケーション概要

### プロダクト名

クイズアプリ - Webブラウザ上で動作するインタラクティブなクイズアプリケーション

### 主要機能

1. **クイズ機能** - 複数選択式・入力式の問題に回答
2. **結果表示** - スコア・正解率・詳細解説の表示
3. **履歴管理** - 過去のクイズ結果の記録・閲覧
4. **レスポンシブUI** - モバイル・タブレット・デスクトップ対応

## ユーザー体験（UX）

### ターゲットユーザー

- 学習意欲のある個人ユーザー
- 知識確認を行いたいユーザー
- 手軽にクイズを楽しみたいユーザー

### ユーザージャーニー

1. **ホーム画面** - アプリの説明と機能紹介
2. **クイズ開始** - 「クイズを始める」ボタンから開始
3. **問題回答** - 10問の質問に順次回答
4. **即座フィードバック** - 各問題の正誤と解説を確認
5. **結果確認** - 総合スコアと詳細結果を表示
6. **履歴閲覧** - 過去の成績を確認

### UX原則

- **シンプルさ** - 直感的で分かりやすいインターフェース
- **即座性** - 回答後の即座なフィードバック
- **継続性** - 履歴機能による学習進捗の可視化
- **アクセシビリティ** - 全ユーザーが利用可能な設計

## 機能仕様

### クイズ機能

- **問題形式**: 複数選択式（4択）・テキスト入力式
- **問題数**: 1セッション10問
- **出題順**: データベースからランダム選択
- **回答方式**: 1問ずつ順次回答
- **フィードバック**: 正誤判定・解説表示・次問への遷移

### スコアリング

- **基本スコア**: 正解数をそのままスコアとする
- **正解率**: パーセンテージで表示（小数点第1位まで）
- **詳細結果**: 各問題の正誤・ユーザー回答・正解・解説

### セッション管理

- **匿名ユーザー**: ユーザー登録不要
- **セッションID**: ブラウザのlocalStorageで管理
- **履歴保存**: セッションIDに紐づけてデータベースに保存
- **履歴表示**: 最新50件まで、日時降順で表示

## UI/UXガイドライン

### デザインシステム

- **カラーパレット**: shadcn/uiのデフォルトテーマ
- **タイポグラフィ**: Geistフォント（Sans・Mono）
- **コンポーネント**: shadcn/ui + Radix UIベース
- **アイコン**: Lucide React

### レスポンシブデザイン

- **モバイル**: 320px〜768px
- **タブレット**: 768px〜1024px
- **デスクトップ**: 1024px以上
- **ブレークポイント**: Tailwind CSSの標準設定

### アクセシビリティ

- **ARIA属性**: 適切なラベルと説明
- **キーボードナビゲーション**: Tab・Enter・Spaceキー対応
- **スクリーンリーダー**: 音声読み上げ対応
- **コントラスト**: WCAG 2.1 AA準拠

### インタラクション

- **ホバーエフェクト**: 選択肢・ボタンのハイライト
- **フォーカス状態**: キーボードナビゲーション時の視覚的フィードバック
- **ローディング状態**: データ取得中の表示
- **エラー状態**: ユーザーフレンドリーなエラーメッセージ

## コンテンツ規約

### 問題作成ガイドライン

- **質問文**: 明確で理解しやすい日本語
- **選択肢**: 4つの選択肢、1つの正解
- **解説**: 学習効果を高める詳細な説明
- **難易度**: 一般的な知識レベル

### テキスト規約

- **言語**: 日本語
- **敬語**: 丁寧語を基本とする
- **メッセージ**: ポジティブで励ましの言葉
- **エラーメッセージ**: 分かりやすく解決策を提示

## パフォーマンス要件

### 応答時間

- **ページ読み込み**: 3秒以内
- **問題表示**: 1秒以内
- **回答処理**: 1秒以内
- **結果表示**: 2秒以内

### データ量

- **問題数**: 最低10問、推奨50問以上
- **履歴保存**: ユーザーあたり最大50件
- **画像**: 使用しない（テキストベース）

## 品質基準

### テストカバレッジ

- **単体テスト**: 80%以上
- **E2Eテスト**: 主要フロー100%カバー
- **アクセシビリティテスト**: 自動・手動テスト実施

### ブラウザサポート

- **Chrome**: 最新版
- **Firefox**: 最新版
- **Safari**: 最新版
- **Edge**: 最新版

### モバイル対応

- **iOS Safari**: iOS 14以降
- **Android Chrome**: Android 8以降
