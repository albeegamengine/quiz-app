# 要件定義書

## はじめに

このドキュメントは、Web ブラウザ上で動作するクイズアプリケーションの要件を定義します。ユーザーは複数のクイズに挑戦し、スコアを記録・確認できるシンプルなアプリケーションです。

技術スタック：

- TypeScript
- React (Tailwind CSS + shadcn/ui)
- Next.js (フルスタックフレームワーム)
- データベース: Neon / Supabase / Hono（無料プラン対応）
- Git 管理
- デプロイ: vercel
- 単体テスト
- 結合テスト
- e2e テスト(playwright)
- リンター: ESLint

## 要件

### 要件 1: クイズの表示と回答

**ユーザーストーリー:** ユーザーとして、クイズの質問を見て選択肢から回答を選び、正解・不正解を確認したい。

#### 受入基準

1. WHEN ユーザーがクイズページにアクセスした THEN システムは最初の質問と選択肢を表示すること
2. WHEN 入力形式のクイズに対してユーザーが回答を入力した THEN システムは回答を記録し、正誤判定を行い正解・不正解を即座に表示すること
3. WHEN 選択形式のクイズに対してユーザーが回答を選択した THEN システムは回答を記録し、正誤判定を行い正解・不正解を即座に表示すること
4. WHEN ユーザーが回答を入力した THEN システムは正解の場合は緑色、不正解の場合は赤色でフィードバックを表示すること
5. WHEN ユーザーが正否・解答解説を確認した THEN システムは「次へ」ボタンを表示し、次のクイズに進めるようにすること
6. IF 最後の質問に回答した後正否・解答解説を確認した THEN システムは結果画面に遷移すること

### 要件 2: クイズ結果の表示

**ユーザーストーリー:** ユーザーとして、クイズ終了後に自分のスコアと正解率を確認したい。

#### 受入基準

1. WHEN ユーザーがすべての質問に回答した THEN システムは結果画面を表示すること
2. WHEN 結果画面が表示された THEN システムは正解数、不正解数、正解率（パーセンテージ）を表示すること
3. WHEN 結果画面が表示された THEN システムは各質問の正解・不正解の詳細を表示すること
4. WHEN 結果画面が表示された THEN システムは「もう一度挑戦」ボタンを表示し、クイズを最初からやり直せるようにすること
5. WHEN 結果画面が表示された THEN システムは「ホームに戻る」ボタンを表示すること

### 要件 3: クイズデータの管理

**ユーザーストーリー:** システム管理者として、クイズの質問と選択肢をデータベースで管理したい。

#### 受入基準

1. WHEN システムが起動した THEN システムはデータベースからクイズデータを取得すること
2. IF データベースにクイズデータが存在する THEN システムはそのデータを使用してクイズを表示すること
3. WHEN クイズデータを取得する THEN システムは質問文、選択肢（複数）、正解のインデックスを含むこと
4. IF データベース接続に失敗した THEN システムはエラーメッセージを表示すること
5. WHEN クイズデータが取得された THEN システムは質問をランダムまたは順番に表示できること

### 要件 4: ユーザーインターフェース

**ユーザーストーリー:** ユーザーとして、直感的で使いやすいインターフェースでクイズに取り組みたい。

#### 受入基準

1. WHEN ユーザーがアプリにアクセスした THEN システムはレスポンシブデザインで表示すること（モバイル・タブレット・デスクトップ対応）
2. WHEN ユーザーはブラウザを拡大または縮小した THEN システムはレスポンシブデザインで表示し、コンポーネントの配置や形状が崩れないように表示すること（モバイル・タブレット・デスクトップ対応）
3. WHEN クイズが表示された THEN システムは現在の質問番号と総質問数を表示すること（例: 1/10）
4. WHEN ユーザーが選択肢にホバーした THEN システムは視覚的なフィードバック（ハイライト）を提供すること
5. WHEN ページが読み込まれた THEN システムはローディング状態を表示すること
6. WHEN エラーが発生した THEN システムはユーザーフレンドリーなエラーメッセージを表示すること

### 要件 5: スコア履歴の記録

**ユーザーストーリー:** ユーザーとして、過去のクイズ結果を確認して自分の進捗を追跡したい。

#### 受入基準

1. WHEN ユーザーがクイズを完了した THEN システムは結果をデータベースに保存すること
2. WHEN 結果が保存される THEN システムはタイムスタンプ、スコア、正解率を記録すること
3. WHEN ユーザーが履歴ページにアクセスした THEN システムは過去のクイズ結果一覧を表示すること
4. WHEN 履歴が表示された THEN システムは最新の結果から順に表示すること
5. IF 履歴が存在しない THEN システムは「まだクイズに挑戦していません」というメッセージを表示すること

### 要件 6: ホーム画面とナビゲーション

**ユーザーストーリー:** ユーザーとして、ホーム画面からクイズを開始したり履歴を確認したりできるようにしたい。

#### 受入基準

1. WHEN ユーザーがアプリのルート URL にアクセスした THEN システムはホーム画面を表示すること
2. WHEN ホーム画面が表示された THEN システムは「クイズを始める」ボタンを表示すること
3. WHEN ホーム画面が表示された THEN システムは「履歴を見る」ボタンを表示すること
4. WHEN ユーザーが「クイズを始める」をクリックした THEN システムはクイズページに遷移すること
5. WHEN ユーザーが「履歴を見る」をクリックした THEN システムは履歴ページに遷移すること
6. WHEN ユーザーが任意のページにいる THEN システムはナビゲーションバーまたはヘッダーを表示し、ホームに戻れるようにすること

### 要件 7: データベース初期設定

**ユーザーストーリー:** 開発者として、データベースのスキーマとサンプルデータを簡単にセットアップしたい。

#### 受入基準

1. WHEN プロジェクトをセットアップする THEN システムはデータベーススキーマを定義するマイグレーションファイルを含むこと
2. WHEN データベースが初期化される THEN システムはクイズテーブルとスコア履歴テーブルを作成すること
3. WHEN 初期セットアップが実行される THEN システムは少なくとも 10 問のサンプルクイズデータを投入すること
4. IF Neon/Supabase/Hono のいずれかを使用する THEN システムは環境変数で接続情報を管理すること
5. WHEN データベース接続が設定される THEN システムは接続文字列を.env ファイルで管理し、.gitignore に含めること
